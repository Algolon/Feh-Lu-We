# VFC-01 — craft geometry

Fresh reconstructed experiment, six objects: Library freestanding stack, north bookcase, reading table; cottage table and two canopy posts. Layout, collision, gameplay/interaction IDs and architectural envelope are untouched.

The scoped part-level Batcher hook tests bounding containment and timber identity. Only rectangular 12-triangle members in those object volumes are replaced. Already rounded/tapered/turned/profiled production shapes remain. The edge radius is min(12mm, 14% of smallest dimension), one segment, using the existing softBox construction. **59 members** receive it; this is six objects, not 59 object remodels.

V2 reconstructs the original six-face affine UV transforms for the new topology and uses production families/tints. V1/V3 timber uses local construction-axis grain. New beveled vertices do not introduce an artist-authored weighted-normal system; supplied normals remain generated by the existing kit. Flat-normal micro-control is captured separately on identical topology.

Ten connected members explain support: four canopy knee braces ending in post/beam joints and H-stretchers on two tables, matching the production leg coordinates. Their source count is **1,080 triangles**. Total unique source geometry rises **735,863 → 742,607 (+6,744)**, including bevels. Source sums are unique referenced geometry index/vertex lengths divided by three, not instance-expanded camera work; batched allocation capacity can overstate authored topology. The local increment is stable because those baseline containers are unchanged.

## Assessment

**OBSERVED:** the canopy braces are constructionally readable from the player/craft approaches and in clay. They explain a support system rather than simply increasing surface subdivisions. Reading-table lower framing connects its leg pairs; intervening chairs/props partly occlude it.

**OBSERVED:** Library case edge improvements are strongest under neutral/craft inspection; crowded books and the existing baseline joinery dominate player-distance identity. The geometry-only normal player change is modest. This is a useful diminishing-return finding, not a reason to subdivide every shelf.

**INFERRED:** visible silhouettes/supports and selected lit edges offer better value than micro-book polygons. A 6,744-triangle local increment is small relative to these views, but multiplying it estate-wide still costs geometry memory/submission and shadow work.

## Normals and authored assets

Clean planar faces plus restrained shaped edges are **SELECTIVE**. Flat/smooth controls isolate normal treatment from topology; do not adopt a general weighted-normal pipeline from this sample. Weighted/custom normals remain **DEFER** pending a genuine matched hero object under neutral light.

The optional authored GLB pilot was **not performed**. Exporting identical code geometry to GLB would only test packaging, not authored modelling quality. Code-first is sufficient for these modular furniture/support pilots. Authored GLB may help curved, carved, asymmetric or mechanically specific hero silhouettes; quality/triangles/calls/materials/load/iteration/reuse require a real matched-object comparison. No measured GLB win is claimed, and Blender is not mandatory.

| Technique | Decision | Reason |
|---|---|---|
| Correct connected load-bearing supports | ADOPT principle / SELECTIVE assets | Normal/clay readability for bounded cost |
| Selected edge profiles | SELECTIVE | Edge/silhouette gain survives some approaches; Library wide gain limited |
| Bevel every object | REJECT | Existing baseline already shaped; multiplication without established distance return |
