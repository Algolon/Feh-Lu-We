## Models and dressing

59 mushroom instances: 20 approach specimens, nine clearing heroes and 30 young companions. Both path verges increase in scale with irregular offsets, yaw and species. The southwestern opening remains clear; only larger stems have colliders.

| Family | Form | Palette |
|---|---|---|
| wine-shelf | Broad, low, irregular shelf | Burgundy / cream / mint lamellae |
| violet-bell | Deep rounded bell | Violet / lavender / pale stem |
| mint-lantern | Tall pointed cap, wavy lip | Dark turquoise / luminous mint |
| rose-spire | Slender curved stem and compact cap | Warm rose / cream / mint |

Models are authored ring surfaces with asymmetry, curved fluted stems, root flare, folded radial gill geometry, curled cap lips and irregular flattened raised scales. Vertex painting supplies broad shading and radial grooves without image textures. They are original procedural meshes informed by the five provided visual references; no reference image is shipped as a game texture.

Eight instanced meshes share one rough standard material: four detailed hero geometries and four lighter geometries for small specimens. Folded luminous foliage forms small base tufts in one additional mesh. Terrain-conforming additive light pools, two unshadowed point lights and 64 soft spores provide spill and atmosphere. The point lights are bounded to 10–11 m; the complete grove is hidden beyond 65 m. Shadows are not generated by the mushrooms. Pulse and spore movement stop with reduced motion.

## Camera, atmosphere and audio

`mushroomField.ts` combines a soft radial clearing field with a tapered approach corridor and exponential time easing. Entry has no hard trigger. Exit snaps the negligible remaining tail to exactly zero. The field is disabled on other floors/scenes and indoors.

`MushroomVision` renders the world to one colour/depth target only while the eased field is nonzero, then runs one fullscreen pass: slow two-axis breathing, chromatic contour separation, slow cool colour drift, highlight diffusion, coloured vignette and depth-based animated fog. Nearby ground stays readable; more distant trees disappear into purple/blue haze. Scene fog, environment lights, dusk progression and game state are not overwritten. HTML UI is outside this pass.

Low quality uses 80% linear target resolution and four glow taps; high uses native drawing-buffer resolution and eight taps. Depth is linearised from camera near/far. Resize and portrait orientation recreate the target dimensions as needed. Context loss and scene switches dispose the target; restoration recreates it. Outside the field the original direct render path is used. There is no history buffer or visual trail pass.

Reduced motion fixes shader time to zero, disables displacement/colour separation and freezes physical pulses/spores. The persistent Dutch setting **Dromerige schermvervorming** independently disables displacement/colour separation while retaining the physical environment, fog and sound.

The original Web Audio score uses five softly detuned stereo sine pads, four suspended/add9 chord voicings moving every 18 s, and an eight-note sparse glass/chime sequence with finite delayed echoes. All zone sound returns through one gain bus upstream of the existing master/mute chain. Existing forest wind fades down and ordinary ambient events are suppressed as the grove takes over. Exit and pause fade the entire bus, including chime tails. Existing Start gesture, context suspension/resume and mute logic are reused; there are no external audio assets.

## Reproduce and review

Run `npm ci`, `npm run typecheck`, `npm test`, `npm run test:budget`, `npm run build`, then `node scripts/mushroom-qa.mjs`. The harness starts its own local static server. Set `CHROME` if needed; its default here is the installed Chromium 141 headless shell. `CHECKS=1` runs route, audio, accessibility and recovery checks; `BENCH=1` adds landscape software GPU timings; `CLIP=1` captures the collision-walk frames. `DIST=../baseline/dist TAG=baseline` measures a separately built untouched baseline. Existing full suite: `CHROME=... node scripts/with-preview.mjs e2e.mjs`.

The source-only patch applies from the exact production base with `git apply --check FEH-LU-WE-Mushroom-Grove-R01.patch` followed by `git apply FEH-LU-WE-Mushroom-Grove-R01.patch` on a new branch. No production merge or deployment is included.

## Remaining limits and one polish iteration

No visual trails (intentional mobile/readability tradeoff), no volumetric raymarched fog, no new notebook entry, and no hardware performance sign-off. The environment is camera-fogged rather than a volume visible from every distant viewpoint. Small specimens have cheaper geometric detail; the four reusable hero species share their overall curvature within each family.

Suggested MG-R02 polish, after the hardware pass: add two unique hero silhouettes with deeper spiral stem carving, reduce long-distance visibility of the clearing with a few carefully placed existing woodland-kit screens, and tune emissive spill/fog against the measured phone display. Keep the collision lane and renderer architecture unchanged. If phone pacing is inadequate, prioritise distance LOD and the post target scale before adding geometric detail.
