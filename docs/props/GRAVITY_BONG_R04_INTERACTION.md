# Gravity bong R04 — Neem een hit

Optional vignette on the existing 2/3-scale commercial gravity bong in the social garden.

- An action prompt 'Neem een hit' appears when aiming at the bong within 2.45 m.
- Original Web Audio effect (~3 seconds): an airy inhalation, irregular water bubbling and a soft exhale.
- User's YouTube link is an inspiration for the sound, not an audio file copied into the game.
- Text toast confirms the action for muted playback; 3.4-second cooldown prevents overlapping sounds.
- No interaction with inventory, clues, progress, save data or other props. No 3D model changes.
- Unit tests cover picking, label, placement, cooldown, and a short irregular bubble pattern.
- Audio similarity still requires listening on a physical Android device.
