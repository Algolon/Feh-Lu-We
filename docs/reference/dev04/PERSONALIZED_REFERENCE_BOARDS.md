## Shared Feh Lu We visual grammar carried by both boards

- Crafted stylized European woodland manor.
- Broad, sturdy forms; not blockout cubes.
- Selective softness/bevels where material/use justifies it.
- Construction remains understandable at close first-person distance.
- Warm timber/plaster/stone and restrained earthy color.
- Small lively accents rather than saturated surfaces everywhere.
- Material identity comes from geometry + authored shading + restrained texture.
- BOSLUST remains the strongest in-game calibration target.
- Portugal exterior remains the second strongest in-game calibration target.
- Current living-room sofa/armchair direction is an owner-approved candidate target.

## Usage rule

For each subject:
- external web references = real-world construction + supporting style examples;
- personalized generated board = Feh Lu We-specific synthesis;
- current-build calibration = protects what already works.

Never copy a generated detail blindly when it conflicts with the actual estate layout, collision, puzzle evidence, or canonical footprint.
