# Personalized reference — Modular book family

Approved generated direction.

## Build a reusable family rather than one mesh with recolors

Target basis:
- 3 closed sizes: small / medium / tall;
- at least 2 thickness classes;
- hard cover with visible cover overhang;
- separate paper block;
- readable spine;
- open-flat variant;
- half-open/reading variant;
- stacked arrangements generated from the base family.

## Variation
Use controlled variation in:
- cloth/leather/paper cover family;
- red, moss/green, blue, ochre/brown and neutral accents;
- spine construction and limited ornament;
- page-edge age/value;
- size/thickness.

Current build already has useful colour/height/tilt/stack variation. Do **not** solve this by adding more random transforms; solve the underlying model construction first.
