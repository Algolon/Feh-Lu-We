## Collection quality test

Before ticking a folder complete, ask:

- Can I see how the object/space is actually built?
- Can I understand what supports what?
- Is the useful detail visible at first-person game distance?
- Does this help stylize rather than merely copy reality?
- Is this meaningfully different from the references already present?

If the answer is mostly no, find a better reference rather than adding more weak ones.
